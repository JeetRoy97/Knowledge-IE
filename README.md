# Public Dataset Samples

This repository contains public samples of four Hindi disaster information extraction datasets. These files are subsets of the complete datasets.

## Files

| File | Coverage | Sample rows |
| --- | --- | ---: |
| `uk_dataset_sample.csv` | Uttarakhand tweets | 50 |
| `turki_dataset_sample.csv` | Turkey–Syria earthquake tweets | 50 |
| `afman_dataset_sample.csv` | Amphan cyclone tweets | 50 |
| `news_dataset_sample.csv` | News covering 14 disaster groups | 50 |

## Sampling

Each file contains **50 samples**, for **200 samples in total**. The news sample covers all 14 original `disaster` groups: the first eight groups in alphabetical order contribute four rows each, and the remaining six contribute three rows each. The three tweet files each represent one disaster dataset.
